# Vector field visualizer — режим LIC

Приложение для визуализации двумерных векторных полей: стрелки, линии тока (Matplotlib) и
собственная реализация метода линейной интегральной свёртки (LIC).

## Возможности
- поля: равномерный поток, источник, сток, вихрь, вихреисточник, диполь, седло (тест), суперпозиция;
- режимы: стрелки / линии тока / LIC; стрелочное наложение на LIC;
- параметры LIC: разрешение изображения, длина свёртки (px), шаг интегрирования (px);
- явная маска сингулярных центров (красный круг), время расчёта, сохранение PNG.

## Запуск
    pip install -r requirements.txt
    streamlit run app.py

## Тесты и эксперименты
    python -m pytest tests                 # 6 автотестов
    python experiments/checks.py           # проверки корректности -> checks.json
    python experiments/experiments.py      # рисунки (figures/) и замеры времени -> timing.json

Скрипты экспериментов запускайте из корня проекта.

## Структура
- `lic.py` — поле на сетке, билинейная интерполяция, RK2, LIC (NumPy), эталон на чистом Python, тестовые поля
- `render.py` — отрисовка режимов без зависимости от Streamlit
- `app.py` — веб-интерфейс Streamlit
- `tests/test_lic.py` — автотесты
- `experiments/` — воспроизводимые проверки и замеры

## Ограничения
Прямоугольное ядро, один интегратор (RK2), поля на регулярной сетке в квадратных пикселях.
Симметричный LIC не различает направление: источник и сток дают одно изображение.
